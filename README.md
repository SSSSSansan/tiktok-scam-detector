# 📡 Scam Radar: TikTok Fraud Detection

**Scam Radar** — это система автоматического обнаружения скрытого мошенничества в коротких видео (TikTok/Instagram). Проект анализирует видеоряд, текст на экране и аудиодорожку, чтобы выявить фейковые инвестиционные платформы, финансовые пирамиды, рекламу нелегального беттинга, скам-розыгрыши и сомнительные предложения о работе.

## 🌟 Ключевые возможности
* **Мультимодальный анализ:** Совместное использование распознавания речи (ASR) и текста на кадрах (OCR + поиск QR-кодов).
* **LLM-Судья:** Языковая модель (OpenAI) анализирует извлеченные «улики» и выносит вердикт с подробным объяснением.
* **Калибровка риска (Risk Score):** Вероятности, выданные LLM, проходят через слой калибровки для выдачи надежного `Risk Score` от 0 до 1.
* **Интерактивное демо:** Готовый веб-интерфейс на Streamlit с визуализацией таймлайна улик и градиентной шкалой риска.

## 🚀 Быстрый старт (Запуск в 3 команды)

Убедитесь, что у вас установлен Python 3.8+ и скачан проект. Выполните в терминале следующие команды:

**1. Установите зависимости:**
```bash
pip install -r requirements.txt

```

**2. Подготовьте данные (скачивание видео и извлечение OCR/ASR):**

```bash
python tools/run_all_asr.py --download --only tiktok
python src/ocr.py --all --only-tiktok

```

*(Примечание: для демо-режима предрассчитанные результаты уже лежат в `data/cache/` и `data/judge_results_asr.csv`)*

**3. Запустите Streamlit-демо:**

```bash
streamlit run app/streamlit_app.py

```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## 📁 Структура проекта

* `app/` — frontend-часть проекта. Файл `streamlit_app.py` содержит демо-интерфейс.
* `src/` — основной пайплайн:
* `frames.py` — извлечение кадров из видео.
* `ocr.py` — извлечение текста с кадров (EasyOCR) и детекция QR-кодов.
* `llm_judge.py` — промпты и логика запросов к LLM для классификации.


* `tools/` — утилиты для работы с датасетом, включая `adversarial.py` для тестирования модели на сложных кейсах (Hard Negatives).
* `data/` — датасеты, кэш распознанного текста (`.ocr.json`, `.asr.json`) и файлы разметки (`labels.csv`).
* `results/` — сгенерированные отчеты по метрикам, калибровке (Reliability & Confusion Matrices) и Adversarial-тестированию.
* `models/` — сохраненные веса калибратора (`calibrator.joblib`).

## 📊 Категории выявления (Scam Categories)

1. **Investment platform**
2. **Pyramid**
3. **Betting**
4. **Giveaway**
5. **Job offer**
6. **none** (безопасный контент, включая официальные розыгрыши брендов — Hard Negatives)

## ⚠️ Ограничения (Limitations)

* В текущей версии для извлечения казахского текста на экране используется `ru`-модель OCR (EasyOCR), что может приводить к неточностям на специфичных символах (ә, ғ, қ, ң, ө, ұ, ү, һ, і).
* Полный расчет Risk Score требует вызова API OpenAI (LLM-судья запускается отдельно от интерфейса загрузки новых файлов для экономии бюджета).
